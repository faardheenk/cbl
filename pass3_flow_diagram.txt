# Pass 3 Flow Diagram

## INPUT DATA
┌─────────────────┐    ┌─────────────────┐
│   CBL Records   │    │ Insurer Records │
│ (Unmatched)     │    │ (Available)     │
│                 │    │                 │
│ ABC Ltd         │    │ ABC Limited     │
│ ABC Limited     │    │ ABC Corp        │
│ XYZ Corp        │    │ XYZ Corporation │
│ DEF Ltd         │    │ DEF Ltd         │
└─────────────────┘    └─────────────────┘

## STEP 1: NAME CLUSTERING (Fuzzy Matching)
┌─────────────────────────────────────────────────────────────────┐
│                    CBL Name Clusters                           │
├─────────────────────────────────────────────────────────────────┤
│ Cluster 1: "ABC Ltd"      → [CBL_1, CBL_2]                     │
│ Cluster 2: "XYZ Corp"     → [CBL_3]                            │
│ Cluster 3: "DEF Ltd"      → [CBL_4]                            │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                  Insurer Name Clusters                         │
├─────────────────────────────────────────────────────────────────┤
│ Cluster 1: "ABC Limited"   → [INS_1, INS_2]                    │
│ Cluster 2: "XYZ Corp"      → [INS_3]                           │
│ Cluster 3: "DEF Ltd"       → [INS_4, INS_5]                    │
└─────────────────────────────────────────────────────────────────┘

## STEP 2: CLUSTER MATCHING
┌─────────────────────────────────────────────────────────────────┐
│                    Cluster Comparisons                          │
├─────────────────────────────────────────────────────────────────┤
│ CBL "ABC Ltd" vs INS "ABC Limited"     → 95% → MATCH!          │
│ CBL "XYZ Corp" vs INS "XYZ Corp"       → 100% → MATCH!         │
│ CBL "DEF Ltd" vs INS "DEF Ltd"         → 100% → MATCH!        │
└─────────────────────────────────────────────────────────────────┘

## STEP 3: NAME GROUPS CREATION
┌─────────────────────────────────────────────────────────────────┐
│                        NAME GROUPS                             │
├─────────────────────────────────────────────────────────────────┤
│ NAME_GROUP_1: CBL[1,2] ↔ INS[1,2] → EXACT MATCH                │
│ NAME_GROUP_2: CBL[3]    ↔ INS[3]   → EXACT MATCH                │
│ NAME_GROUP_3: CBL[4]    ↔ INS[4,5] → PARTIAL MATCH             │
└─────────────────────────────────────────────────────────────────┘

## STEP 4: INDIVIDUAL RECORD MATCHING
┌─────────────────────────────────────────────────────────────────┐
│                    Individual Matches                          │
├─────────────────────────────────────────────────────────────────┤
│ CBL_1 → INS[1,2] (Exact Match)                                │
│ CBL_2 → INS[1,2] (Exact Match)                                │
│ CBL_3 → INS[3]   (Exact Match)                                │
│ CBL_4 → INS[4,5] (Partial Match)                              │
└─────────────────────────────────────────────────────────────────┘

## STEP 5: GROUP MERGING (if needed)
┌─────────────────────────────────────────────────────────────────┐
│                    Merged Groups                               │
├─────────────────────────────────────────────────────────────────┤
│ If NAME_GROUP_1 and NAME_GROUP_2 share insurer records:       │
│ MERGED_GROUP_1: CBL[1,2,3] ↔ INS[1,2,3]                       │
│                                                                 │
│ All CBL records in merged group get same match status         │
└─────────────────────────────────────────────────────────────────┘

## FINAL RESULT
┌─────────────────────────────────────────────────────────────────┐
│                        Final Matches                           │
├─────────────────────────────────────────────────────────────────┤
│ CBL_1: "ABC Ltd"      → INS[1,2] (Exact Match)                │
│ CBL_2: "ABC Limited"  → INS[1,2] (Exact Match)                │
│ CBL_3: "XYZ Corp"     → INS[3]   (Exact Match)                │
│ CBL_4: "DEF Ltd"      → INS[4,5] (Partial Match)              │
└─────────────────────────────────────────────────────────────────┘

## KEY CONCEPTS:
1. NAME CLUSTERS: Groups of similar company names (fuzzy matching)
2. NAME GROUPS: Matches between CBL and insurer clusters
3. MERGED GROUPS: Groups that share insurer records
4. CLUSTER-LEVEL DECISIONS: All records in cluster get same status
5. SHARED INSURER RECORDS: Multiple CBL records can share insurers
